# 11: 售后审核与仅退款闭环

**What to build:** 人工客服可以审核申请，未发货退款及鲜梨品质仅退款可以完成沙箱原路退款；退款金额受可退额度限制，审核、退款和库存释放均有真实状态与审计记录。

**Blocked by:** 05: 人工接管与客服认领; 10: 售后凭证上传与申请提交

**Status:** ready-for-agent

- [ ] 有权限的人工客服或管理员可以查看待审核申请及凭证，并通过或拒绝申请；智能客服不能代替审核。
- [ ] 已支付未发货订单可以完成仅退款，退款成功后释放对应预占库存且不要求顾客退货。
- [ ] 鲜梨品质问题可以审核为仅退款且原则上不要求寄回生鲜，退款或拒绝原因对顾客可见。
- [ ] 沙箱退款原路关联原支付单并保存独立退款单及状态，不冒充真实资金操作。
- [ ] 支持商品行部分退款，多次售后累计退款不能超过该行实付可退金额，客服不能任意填写超额金额。
- [ ] 重复审核、重复退款请求和支付工具重试不会造成重复退款或重复库存释放。
- [ ] 人工客服只能处理自己认领会话的关联售后，管理员操作及所有审核和退款结果均保留审计。
- [ ] 接口测试覆盖审核权限、未发货退款、鲜梨部分退款、退款上限、幂等和审计。
