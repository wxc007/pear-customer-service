# 09: 发货、物流查询与确认收货

**What to build:** 管理员可以登记发货及物流状态，顾客可以查询带最后更新时间的物流信息并确认收货；发货满 7 天自动完成，订单与物流状态保持独立且一致。

**Blocked by:** 08: 沙箱支付、取消与超时关单

**Status:** ready-for-agent

- [ ] 管理员可以为已支付待发货订单登记一张普通发货单，记录承运方、物流单号和发货时间。
- [ ] 首期同一订单不能创建多张普通发货单，未支付或已关闭订单不能发货。
- [ ] 管理员可以维护物流状态，顾客只能查看本人订单的承运方、物流单号、状态和最后更新时间。
- [ ] 页面和智能客服明确说明物流信息由商家维护，不冒充承运商实时查询或自行预测进度。
- [ ] 顾客可以确认本人订单收货，系统保存收货时间并将订单推进为已完成。
- [ ] 发货满 7 天未确认的订单自动完成，重复执行自动任务不会重复改变状态。
- [ ] 非法状态跳转和越权发货、查询、确认收货会被拒绝并保留必要审计。
- [ ] 接口测试覆盖发货、物流更新、顾客查询、确认收货、自动完成和权限边界。
