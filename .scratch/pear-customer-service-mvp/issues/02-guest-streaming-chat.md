# 02: 游客流式智能客服会话

**What to build:** 游客获得匿名会话凭证，可以通过 SSE 与智能客服连续对话；智能客服能调用商品查询工具，保存会话与消息，模型故障时明确提示而不编造商品事实，并记录 Agent 与业务事务边界的 ADR。

**Blocked by:** 01: 商品目录与项目纵向骨架

**Status:** done

- [x] 后端可以签发有效期 24 小时的游客会话凭证，游客只能继续自己的匿名会话。
- [x] 简易页面可以通过 SSE 展示文本增量、完成和错误事件，消息及必要结果先持久化再发送。
- [x] 同一游客会话可以连续多轮咨询，全量消息入库，模型只使用有限近期消息和摘要。
- [x] 智能客服通过白名单商品工具获取实时 SPU、SKU、价格和可售状态，不依赖模型记忆回答动态事实。
- [x] 模型不能执行任意 SQL、URL、文件系统或系统命令，用户消息中的指令不能改变系统规则。
- [x] 模型超时或不可用时返回诚实、可理解的失败结果，不伪造商品信息或业务成功。
- [x] 自动化测试使用可控模型替身验证 REST、SSE、持久化和故障行为，不调用真实模型。
- [x] ADR 记录单 Agent 与确定性业务事务的边界。
