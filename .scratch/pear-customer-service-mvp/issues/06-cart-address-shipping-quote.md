# 06: 购物车、收货地址与配送试算

**What to build:** 登录用户可以维护地址、管理购物车、合并 SKU、勾选部分商品，并获得实时的配送范围、商品金额、运费和应付金额试算。

**Blocked by:** 04: 顾客认证、会话归属与历史

**Status:** ready-for-agent

- [ ] 登录用户可以维护自己的多个收货地址并设置默认地址，不能读取或修改他人地址。
- [ ] 每个用户只有一个有效购物车，同一 SKU 重复加购会合并数量。
- [ ] 每种 SKU 数量不能超过 99，购物车最多 50 种 SKU，超限会明确提示且不会静默减量。
- [ ] 购物车不预占库存，价格、可售状态和配送条件在试算时重新获取。
- [ ] 用户可以勾选部分商品行进行试算，未选商品保持原购买意向。
- [ ] 收货地址不在配送范围时明确不可下单，配送范围内展示商品金额、区域运费和应付总额，不计算订单优惠。
- [ ] 智能客服可以在用户明确授权后执行加购，并使用真实试算结果解释金额。
- [ ] 简易页面和接口测试覆盖地址、购物车、部分勾选、超限时提示和配送试算。
