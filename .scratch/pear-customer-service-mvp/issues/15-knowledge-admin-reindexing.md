# 15: 知识资料运营与索引重建

**What to build:** 管理员可以录入或导入知识资料，管理版本、发布、停用和向量化状态，并重建及校验 Qdrant 索引；只有发布且索引成功的版本参与回答。

**Blocked by:** 03: 政策知识问答与来源引用; 04: 顾客认证、会话归属与历史

**Status:** ready-for-agent

- [ ] 管理员可以手动录入或导入 Markdown、纯文本资料，顾客和人工客服不能修改知识库。
- [ ] 知识资料支持草稿、新版本、发布和停用，历史版本及来源信息可以追溯。
- [ ] 未发布、已停用或向量化失败的版本不参与智能客服检索和回答。
- [ ] 发布过程记录分段、向量化和索引状态，索引成功前不会把资料当作可靠政策答案。
- [ ] 管理员可以重建 Qdrant 索引，重建并校验成功后再切换生效版本，失败时保留明确状态。
- [ ] 更新或停用资料后，后续回答使用正确的生效版本并返回对应文档标题和版本来源。
- [ ] 文档中的恶意指令不能获得额外系统权限，管理操作保留操作者和时间。
- [ ] Testcontainers 测试覆盖导入、版本发布、停用、索引失败、重建切换和回答来源变化。
