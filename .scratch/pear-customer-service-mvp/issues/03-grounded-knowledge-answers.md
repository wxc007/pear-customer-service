# 03: 政策知识问答与来源引用

**What to build:** 智能客服可以基于已发布的售后政策、储存和食用资料回答问题并给出文档版本来源；低相关内容会被拒答，Qdrant 不可用时不会伪造可靠答案，并记录 MySQL＋Qdrant 方案的 ADR。

**Blocked by:** 02: 游客流式智能客服会话

**Status:** in-progress

- [ ] 已发布的演示知识资料可以分段并向量化到 Qdrant，MySQL 保留文档、版本和索引状态事实源。
- [ ] 智能客服默认检索最相关的 5 个片段，并使用可配置阈值排除低相关内容。
- [ ] 政策、储存和食用回答包含可追溯的文档标题及版本来源。
- [ ] 检索不足时明确表示不确定，不使用相似但不相关的资料拼凑答案。
- [ ] 价格、库存和订单等动态事实仍通过实时工具获取，不进入静态知识检索替代链路。
- [ ] 知识文档中的恶意指令只被当作资料内容，不能诱导额外工具权限。
- [ ] Qdrant 不可用时明确说明知识回答暂不可靠，不产生无依据政策承诺。
- [ ] Testcontainers 集成测试覆盖检索、来源、低相关拒答和向量库故障，ADR 记录 MySQL 与 Qdrant 分离方案。
