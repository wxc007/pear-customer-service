# 12: 退货验收与补发履约

**What to build:** 梨制品退货退款支持等待退货、验收和退款，审核通过的补发可以生成独立发货单；品质问题商品不会自动恢复可售库存，运费责任清晰可查。

**Blocked by:** 11: 售后审核与仅退款闭环

**Status:** ready-for-agent

- [ ] 审核通过的梨制品退货退款进入等待退货状态，只有记录退回商品及验收结果后才能退款。
- [ ] 鲜梨品质售后不会被要求走普通退货流程，梨制品无理由退货与质量问题的运费责任对顾客和客服可见。
- [ ] 验收通过后的退款沿用原支付及可退额度约束，验收拒绝会记录原因并使售后状态可追踪。
- [ ] 审核通过的补发会生成关联售后申请的独立发货单，不创建带支付金额的新订单。
- [ ] 补发可以查询承运方、物流单号、状态和最后更新时间，不能对同一申请重复生成补发。
- [ ] 品质问题或退回待处理商品不会自动恢复为可售库存，库存调整只能留下明确记录。
- [ ] 退货、验收、退款和补发的非法状态跳转及越权操作会被拒绝。
- [ ] 接口测试覆盖退货验收、运费责任、补发履约、库存约束、状态机和权限。
