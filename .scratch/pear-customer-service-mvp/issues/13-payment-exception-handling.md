# 13: 支付异常人工处理

**What to build:** 已关闭订单收到支付成功等情况会进入支付异常队列，管理员可以核实并记录处理结果；异常不会被静默忽略，也不会直接绕过订单状态机。

**Blocked by:** 05: 人工接管与客服认领; 08: 沙箱支付、取消与超时关单

**Status:** ready-for-agent

- [ ] 已关闭订单收到支付成功等异常会进入可查询的支付异常队列，并保留原订单、支付单和异常原因。
- [ ] 管理员可以查看异常详情并记录核实结果，普通顾客和无关联人工客服不能读取异常管理信息。
- [ ] 异常处理不能直接改写历史支付事实或绕过订单状态机，只能使用受控处理动作并留下完整审计。
- [ ] 重复异常通知不会生成无法区分的重复异常，也不会重复执行处理动作。
- [ ] 顾客可以通过受控渠道得知异常正在人工核实，而不是收到相互矛盾的支付成功和订单关闭承诺。
- [ ] 异常处理完成后可以追溯处理人、时间、动作和结果。
- [ ] 接口测试覆盖异常入队、重复通知、权限、受控处理和审计。
