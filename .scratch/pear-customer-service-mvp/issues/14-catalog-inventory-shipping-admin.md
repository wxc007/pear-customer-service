# 14: 商品、库存与配送运营管理

**What to build:** 管理员可以通过受保护接口维护分类、SPU、SKU、上下架、现存库存、配送范围和区域运费，并查看预占及库存变更记录；变更会真实影响后续咨询和下单。

**Blocked by:** 07: 两阶段确认下单与库存预占

**Status:** ready-for-agent

- [ ] 管理员可以维护分类、SPU、SKU 及鲜梨和梨制品差异属性，普通顾客和人工客服不能修改。
- [ ] SPU 或 SKU 下架后新咨询和下单会反映不可售状态，历史订单快照保持不变。
- [ ] 商品价格与库存调整使用合法金额、数量和并发控制，不允许出现未解释的负库存。
- [ ] 管理员可以查看现存、预占、可售库存及每次调整、预占、扣减和释放的变更记录。
- [ ] 管理员可以维护配送范围和区域运费，后续试算及下单使用最新规则且历史订单金额不被改写。
- [ ] 非法修改、并发冲突和越权管理操作会明确失败，不会产生部分成功状态。
- [ ] 所有管理变更记录操作者和时间，审计内容不包含无关敏感信息。
- [ ] 接口测试验证管理变更会真实影响商品咨询、配送试算和后续下单，同时保护历史快照。
